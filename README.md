# 던전 편의점 · 실시간 게임 POC

낮에는 직접 움직이며 주문에 맞게 재료를 집고 두 가지를 조합해 손님에게 서빙합니다. 밤에는 던전에서 몬스터에게 가까이 가 자동 공격으로 사냥하고 다음 영업에 사용할 재료를 모읍니다. 낮 60초 → 밤 30초 → 낮 60초로 구성된 싱글 플레이 시제품입니다.

## 조작

- iPhone: 화면 방향 버튼을 누르고 있어 이동, 행동 버튼으로 재료 집기·조리·서빙.
- PC: 방향키 또는 WASD로 이동, 스페이스/엔터로 행동.
- 손님 주문에 표시된 서로 다른 재료 두 가지를 조리대에서 합치고 왼쪽 손님에게 전달하세요. 잘못 만든 음식은 휴지통에 버릴 수 있습니다.
- 밤에는 이동하며 몬스터에게 가까이 가면 자동 공격합니다. 처치하면 재료가 재고에 추가됩니다.

## 실행

GitHub Pages 주소를 iPhone Safari에서 열고 플레이할 수 있습니다. Safari 공유 메뉴의 **홈 화면에 추가**로 웹앱처럼 실행할 수 있습니다. 네이티브 iOS 앱이나 TestFlight 빌드는 아닙니다. 효과음은 상단 버튼으로 끌 수 있으며 기기 설정에 따라 동작이 다를 수 있습니다.

로컬에서는 `python3 -m http.server 8000` 실행 후 `http://localhost:8000`에 접속하세요. 이 POC는 로그인, 저장, 광고, 결제, 멀티플레이를 포함하지 않습니다.
