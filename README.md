# 달빛 편의점 · 새 필드 사냥 POC

기존 `src/dungeon.js`를 사용하지 않고 `src/hunt/`에 캐릭터, 전투, 카메라와 필드를 새로 구성했습니다. 계곡과 다리가 있는 필드에서 몬스터를 선택하고 직접 공격·회피·스킬을 사용해 사냥합니다. 재료는 편의점에 가져와 진열하고 손님에게 팔 수 있습니다.

## 조작

- 왼쪽 화면을 누른 위치에 이동 조이스틱이 나타납니다.
- 몬스터를 탭해 선택한 뒤 공격 버튼으로 사냥합니다. 이동하면서 공격·스킬을 사용할 수 있습니다. 빈 공간을 탭하면 대상 선택이 해제됩니다.
- 국자는 원거리 투사체, 프라이팬은 근거리 공격입니다. 선택한 대상까지의 거리와 사거리 밖 여부를 확인하세요.
- 파동은 범위 스킬이며 쿨다운이 있습니다. 회피는 이동 방향 또는 바라보는 방향으로 대시합니다.
- PC: WASD/방향키 이동, 스페이스 공격, Shift 회피, E 파동.
- 필드 동쪽의 고목 수호자는 선택 도전입니다. 재료를 모으고 입구로 돌아와 귀환하면 편의점의 재고로 인계됩니다.
- 상점에서 버섯 진열 후 손님이 계산대로 오면 판매할 수 있습니다. 수익으로 공격력을 강화하고 다시 사냥할 수 있습니다.

## 실행

Node.js 20 이상에서 `npm install`, `npm run dev`. `npm run build` 결과는 `dist/`에 생성됩니다. GitHub Pages에는 빌드 결과를 게시합니다. iPhone Safari에서 여는 웹 POC이며, 네이티브 iOS 앱/IPA 또는 TestFlight 빌드가 아닙니다.

진행 기록(재고·수익·강화)은 브라우저에 저장됩니다. 브라우저 데이터 삭제 또는 기기 변경 시 기록은 공유되지 않습니다. 계정/서버/멀티플레이, 흥정/도둑, 복수 메뉴, 완성된 성장 콘텐츠는 이번 시제품 범위에 포함되지 않습니다.

새 캐릭터/환경 모델 출처는 `public/assets/models/quaternius-adventurer/README.md`, `public/assets/models/hunt-nature/README.md`와 각 팩 라이선스에 기록했습니다. 실제 iPhone 성능과 손맛은 실기 테스트가 필요합니다.
