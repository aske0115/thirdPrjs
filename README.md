# 달빛 편의점 · 모바일 비주얼 POC

컨셉 기준 이미지에 맞춰 모바일 세로 화면의 분위기와 핵심 UI 흐름을 먼저 확인하는 POC입니다. 달빛 아래 편의점과 버섯 숲 원정의 화면 톤, HUD 배치, 특별 주문·흥정·진열·원정 진입을 직접 눌러 볼 수 있습니다.

## 실행

```sh
npm install
npm run dev
```

`client/concept.js`가 상점·원정 화면 상호작용을 처리하고, `public/assets/concept/`의 WebP 시안이 화면 배경을 구성합니다. 아트 이미지는 이 프로젝트의 컨셉 템플릿으로 생성한 시안입니다. 현재 전투는 공격·스킬·보상 흐름을 확인하는 인터랙션 시뮬레이션이며, 이미지 속 캐릭터를 움직이는 실시간 3D 구현은 아닙니다. 다음 구현은 이 시안의 캐릭터 비율, 배경 밀도, 색감, UI 안전 영역을 기준으로 3D 에셋과 애니메이션을 교체해 나가도록 구성했습니다.

모바일 브라우저의 더블탭 확대와 제스처 확대를 막고, 세이프 에어리어와 멀티터치 포인터를 고려했습니다. 저장 데이터는 브라우저 로컬 저장소에 보관합니다.
