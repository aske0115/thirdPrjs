# 던전 편의점 · iPhone 웹 POC

3일 동안 던전에서 재료를 모아 두 가지를 조합하고, 손님의 취향에 맞는 상품으로 100코인 매출을 노리는 싱글 플레이 시제품입니다.

## 플레이

1. 오늘의 손님 취향을 확인하고 던전을 선택합니다.
2. 보유한 서로 다른 재료 두 개를 골라 예상 매출을 확인한 뒤 판매합니다.
3. 3일간 100코인 이상을 벌어 목표를 달성합니다. 남은 재료는 다음 날로 넘어갑니다.

아이폰에서 HTTPS 주소를 Safari로 열어 플레이하세요. Safari의 공유 메뉴에서 **홈 화면에 추가**하면 웹앱처럼 실행할 수 있습니다. 네이티브 iOS 앱이나 TestFlight 빌드는 아닙니다. 효과음은 오른쪽 위 버튼으로 끌 수 있습니다. 브라우저 정책에 따라 첫 터치 이후 소리가 재생되며 기기 설정에 영향을 받습니다.

## 로컬 실행

별도 패키지 설치 없이 프로젝트 폴더에서 `python3 -m http.server 8000`을 실행하고 `http://localhost:8000`에 접속합니다. 오프라인 캐시와 홈 화면 기능은 HTTPS 또는 localhost가 필요합니다. 로컬 서버를 아이폰에서 열려면 기기 네트워크 및 브라우저 보안 제약을 따로 고려해야 합니다.

## POC 범위

단판 3일 게임, 조합 여섯 종류, 사운드 토글과 간단한 오프라인 캐시를 포함합니다. 저장, 광고, 결제, 로그인, 멀티플레이와 네이티브 앱 빌드는 포함하지 않습니다. iPhone 실기 테스트 전에는 Safari 호환성을 보장할 수 없습니다.
