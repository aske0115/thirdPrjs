# 달빛 편의점 · 3D 모바일 POC

올려주신 컨셉 화면의 달빛 판타지 분위기를 목표로 다시 구성하는 Three.js 모바일 게임 시제품입니다. 상점과 사냥터는 모두 실시간 3D 장면이며, 컨셉 이미지를 화면 배경으로 사용하지 않습니다.

## 실행과 조작

```sh
npm install
npm run dev
```

앱은 3D 상점에서 시작합니다. 왼쪽 화면을 드래그해 주인공을 이동하고, 상점 안에서 진열대·손님·계산대·출구 가까이 간 뒤 오른쪽 행동 버튼을 누르세요. 출구로 나가면 숲에서 몬스터를 직접 선택해 공격·회피·스킬을 쓸 수 있습니다. 이동과 공격은 두 손가락으로 동시에 조작할 수 있습니다. 상점 진행은 브라우저 로컬 저장소에 기록됩니다.

모바일 확대를 막는 viewport 설정, 터치 동작 제한, safe-area 여백을 적용했습니다. Chromium 기반 320/390px 화면에서 이동, 손님 판매, 사냥터 전환, 이동과 전투 동시 입력을 확인했습니다. 실제 iPhone Safari와 장시간 성능은 아직 별도로 검증하지 않았습니다.

이번 빌드는 움직이는 3D 게임플레이 POC입니다. 캐릭터와 환경은 사용할 수 있는 무료 3D 에셋과 생성형 컨셉 시안의 방향을 맞춘 단계이며, 컨셉 화면의 최종 아트 완성도를 달성했다고 보지는 않습니다.
