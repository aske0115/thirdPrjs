# 달빛 편의점 · 3D POC

숲속 편의점의 손님이 버섯을 부탁합니다. 무기를 선택해 두 구역으로 이어진 숲을 탐험하고, 적을 피하며 버섯을 모아 돌아온 뒤 진열대에 올려 손님에게 판매하세요. 판매 수익으로 공격력을 강화하고 다시 탐험할 수 있습니다.

## 조작 및 흐름

- 편의점에서 무기(국자·프라이팬)를 고르고 **버섯 숲으로 떠나기**를 누릅니다.
- 화면 왼쪽 아래 조이스틱으로 이동합니다. **공격**으로 바라보는 방향을 공격하고, **회피**로 이동 방향으로 대시합니다. PC는 방향키/WASD, 스페이스 공격과 Shift 회피를 사용할 수 있습니다.
- 적 세 마리를 잡으면 공격력 또는 공격 범위 강화를 선택할 수 있습니다. 이는 이번 탐험에만 적용됩니다.
- 숲 안쪽 재료 상자를 공격해 버섯을 얻고 입구에서 **귀환**하거나 체력/시간이 다하면 편의점에 돌아옵니다. 소스통을 공격하면 생기는 웅덩이에 돌진하는 적이 기절합니다. 획득품은 보존됩니다.
- **버섯 진열 → 손님에게 건네기**로 부탁을 완료합니다. 판매 수익으로 영구 공격 강화를 구입할 수 있습니다(현재 게임 실행 중에만 유지).

상점에는 시간 제한이 없고 던전은 시제품 검증용으로 180초 제한이 있습니다. 진행 상태는 앱을 새로 열면 초기화됩니다. POC는 흥정·도둑·복수 손님, 완성된 메뉴/시장 시스템, 저장, 광고, 멀티플레이를 포함하지 않습니다.

## 실행 및 배포

Node.js 20 이상에서 `npm install` 후 `npm run dev`를 실행하세요. `npm run build` 결과는 `dist/`에 생성됩니다. 현재 GitHub Pages에 올라간 웹 POC는 iPhone Safari에서 열 수 있으며, 네이티브 iOS 앱/IPA나 TestFlight 빌드는 아닙니다. 실제 iPhone Safari의 성능·오디오·터치 확인이 필요합니다.

모델 출처와 각 원본 CC0 라이선스는 [public/assets/models/README.md](public/assets/models/README.md)에 기록했습니다.
