# Moonlight — 전면 재제작 기준

## 유일한 시각 기준
사용자가 제공한 세로형 모바일 컨셉 이미지 네 장을 제작 기준으로 삼는다.
망치섬, 쓸어킬, 기존 thirdPrjs 구현은 디자인·맵·캐릭터·전투의 기준으로 사용하지 않는다.
기존 구현의 카메라, 절차적 소품, 캐릭터, 맵, 전투 시스템을 개선하거나 재활용하는 방식으로 진행하지 않는다.

## 반드시 실제로 구현할 화면
1. 상점: 목조 아치, 큰 달빛 창, 보라색 꽃과 덩굴, 따뜻한 등불, 풍성한 상품 진열, 이동하는 손님과 점원.
2. 주문: 동일한 살아 있는 상점 안에서 손님과 점원이 대화하고 주문 수락·흥정·거절을 수행한다.
3. 탐험: 깊이 있는 숲길, 개울·폭포·다리·온실 유적, 숨겨진 채집 구역과 귀환 포털을 실제 이동 가능한 공간으로 만든다.
4. 전투: 동일한 숲에서 캐릭터가 직접 검을 휘두르고 몬스터가 반응한다. 공격 궤적, 피격 순간, 경직, 회피, 지면 예고가 동작한다.

## 화면과 조작
- 모바일 세로 화면 전체를 채우는 실제 3D 공간. 배경 그림 위에 버튼을 얹는 구현은 불가.
- 시안의 시점, 캐릭터 크기, 환경 밀도, 색감과 조명을 함께 맞춘다.
- 둥근 얼굴과 큰 눈의 치비 판타지 점원, 크림색 달 장식 모자, 짙은 갈색 머리, 자주색 망토, 앞치마와 부츠.
- 왼손 자유 위치 조이스틱, 오른손 기본 공격·회피·스킬. 이동과 공격 동시 입력 지원.
- 더블탭 확대, 페이지 스크롤, 안전영역 침범 방지.

## 제작 순서와 판정
새 장면·에셋·애니메이션 파이프라인부터 구축한다. 작은 3D 블록을 조합한 임시 장면을 최종 미술로 취급하지 않는다.
먼저 상점 한 구도와 숲 전투 한 구도를 실제 실행 화면으로 완성한다. 시안과 나란히 비교해 카메라·실루엣·밀도·조명이 맞는지 확인한 뒤 기능 범위를 넓힌다.
컨셉 이미지 자체를 실행 화면이라고 제시하지 않는다. 시안 수준을 달성하지 못한 결과를 완료로 보고하지 않는다.
